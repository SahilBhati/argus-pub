# Building a Local AI Assistant with Ollama and Quartz

## Introduction

This tutorial will guide you through setting up a local AI assistant using a Mac mini 24GB with qwen2.5-coder:14b, LangChain tool calling, and automated static publishing.

## Hardware Setup

- **Mac mini 24GB**: Ensure your Mac mini has at least 24GB of RAM to handle the computational demands of running AI models.

## Software Setup

1. **qwen2.5-coder:14b**: Install the qwen2.5-coder:14b model on your Mac mini.
2. **LangChain**: Set up LangChain for tool calling and integration with your AI assistant.
3. **Automated Static Publishing**: Configure automated static publishing using Quartz.

## Conclusion

By following this tutorial, you will have a fully functional local AI assistant running on your Mac mini, leveraging qwen2.5-coder:14b, LangChain, and automated static publishing with Quartz.
