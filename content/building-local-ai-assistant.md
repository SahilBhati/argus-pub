# Building a Local AI Assistant with Ollama and Quartz

> **Summary:** Learn how to set up a local AI assistant using a Mac mini 24GB with qwen2.5-coder:14b, LangChain tool calling, and automated static publishing.

## Building a Local AI Assistant with Ollama and Quartz

This tutorial will guide you through setting up a local AI assistant using a Mac mini 24GB with qwen2.5-coder:14b, LangChain tool calling, and automated static publishing.

### Hardware Setup
- **Mac mini 24GB**: Ensure your Mac mini has at least 24GB of RAM to handle the computational demands of running AI models.

### Software Setup
1. **qwen2.5-coder:14b**: Install the qwen2.5-coder:14b model to provide the core AI capabilities.
2. **LangChain**: Integrate LangChain for tool calling and managing AI workflows.
3. **Automated Static Publishing**: Set up a system for automated static publishing to ensure your assistant's knowledge is always up-to-date.

### Steps to Setup
1. **Install qwen2.5-coder:14b**
   - Follow the installation instructions provided by the qwen2.5-coder:14b documentation.
2. **Configure LangChain**
   - Set up LangChain to interact with qwen2.5-coder:14b and handle tool calls efficiently.
3. **Automate Static Publishing**
   - Use Quartz to automate the publishing process, ensuring your AI assistant's content is always accessible and up-to-date.

### Conclusion
By following this tutorial, you will have a fully functional local AI assistant running on a Mac mini 24GB, leveraging qwen2.5-coder:14b, LangChain, and automated static publishing.
