# Building a Local AI Assistant with Ollama and Quartz

> **Summary:** Learn how to set up a local AI assistant using a Mac mini 24GB with qwen2.5-coder:14b, LangChain tool calling, and automated static publishing.

## Building a Local AI Assistant with Ollama and Quartz

This tutorial will guide you through setting up a local AI assistant using a Mac mini 24GB with qwen2.5-coder:14b, LangChain tool calling, and automated static publishing.

### Hardware Setup
- **Mac mini 24GB**: Ensure your Mac mini has at least 24GB of RAM to handle the computational demands of running AI models.

### Software Setup
1. **qwen2.5-coder:14b**: Install the qwen2.5-coder:14b model on your Mac mini.
2. **LangChain**: Set up LangChain to facilitate tool calling and interaction with the AI model.
3. **Automated Static Publishing**: Configure automated static publishing to Quartz for easy sharing and updates.

### Steps to Follow
1. **Install qwen2.5-coder:14b**
   - Download and install the qwen2.5-coder:14b model on your Mac mini.
2. **Configure LangChain**
   - Set up LangChain to enable tool calling and integrate it with the qwen2.5-coder:14b model.
3. **Set Up Automated Static Publishing**
   - Configure automated static publishing to Quartz to ensure your AI assistant is always up-to-date and accessible.

### Conclusion
By following these steps, you can build a powerful local AI assistant using a Mac mini 24GB with qwen2.5-coder:14b, LangChain tool calling, and automated static publishing. This setup will allow you to leverage the full potential of AI on your local machine.
