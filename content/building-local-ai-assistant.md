## Building a Local AI Assistant with Ollama and Quartz

This tutorial will guide you through setting up a local AI assistant using a Mac mini 24GB with qwen2.5-coder:14b, LangChain tool calling, and automated static publishing.

### Hardware Setup
- **Mac mini 24GB**: Ensure your Mac mini has at least 24GB of RAM to handle the computational demands of running qwen2.5-coder:14b.

### Software Setup
1. **Install qwen2.5-coder:14b**: Follow the official installation guide to set up qwen2.5-coder:14b on your Mac mini.
2. **Configure LangChain**: Integrate LangChain with qwen2.5-coder:14b to enable tool calling and automate tasks.
3. **Set Up Quartz**: Install Quartz and configure it for automated static publishing.

### Automated Static Publishing
- Use Quartz to build and publish your AI assistant setup directly to Cloudflare & GitHub.

## Conclusion
By following this tutorial, you'll have a fully functional local AI assistant running on your Mac mini, leveraging qwen2.5-coder:14b, LangChain, and Quartz for automated static publishing.
